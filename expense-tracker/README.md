# Gelir Gider Hesaplayıcı

## Proje Hakkında

Bu proje, Python programlama dili kullanılarak geliştirilmiş basit bir gelir gider hesaplayıcı uygulamasıdır. Kullanıcının gelir ve gider bilgilerini sisteme eklemesine, toplam gelir ve gider tutarını görüntülemesine ve mevcut bakiyesini hesaplamasına olanak sağlamaktadır.

## Projenin Amacı

Bu proje, Python programlama dilinde temel programlama yapılarını kullanarak menü tabanlı bir uygulama geliştirmek amacıyla hazırlanmıştır. Proje kapsamında kullanıcıdan veri alma, listeler üzerinde işlem yapma ve hesaplama işlemleri gerçekleştirilmiştir.

## Özellikler

- Gelir bilgisi ekleme
- Gider bilgisi ekleme
- Toplam gelir ve gider tutarını hesaplama
- Kalan bakiyeyi görüntüleme
- Menü tabanlı kullanıcı etkileşimi

## Kullanılan Konular

- Python
- Listeler (List)
- Döngüler (`while`)
- Koşul ifadeleri (`if`, `elif`, `else`)
- Kullanıcıdan veri alma (`input`)
- Toplama işlemleri (`sum`)

## Bu Projede Kazandığım Beceriler

Bu proje sayesinde;

- Liste veri yapısını kullanmayı,
- Döngüler ile sürekli çalışan menü yapısı oluşturmayı,
- Koşul ifadeleri ile program akışını yönetmeyi,
- Kullanıcıdan alınan verileri işleyerek hesaplama yapmayı,
- Daha düzenli ve okunabilir Python kodu yazmayı öğrendim.
