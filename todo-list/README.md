# Yapılacaklar Listesi

## Proje Hakkında

Bu proje, Python programlama dili kullanılarak geliştirilmiş basit bir yapılacaklar listesi uygulamasıdır. Kullanıcı yeni görevler ekleyebilir, eklediği görevleri görüntüleyebilir ve dilediğinde programdan çıkış yapabilir.

## Projenin Amacı

Bu proje, Python programlama dilindeki temel programlama yapılarını kullanarak menü tabanlı bir uygulama geliştirmek amacıyla hazırlanmıştır. Proje kapsamında kullanıcıdan veri alma, liste veri yapısı üzerinde işlem yapma ve döngü kullanımı uygulanmıştır.

## Özellikler

- Yeni görev ekleme
- Kayıtlı görevleri listeleme
- Menü tabanlı kullanım
- Programdan güvenli şekilde çıkış yapma

## Kullanılan Konular

- Python
- Listeler
- Döngüler (`while`, `for`)
- Koşul ifadeleri (`if`, `elif`, `else`)
- Kullanıcıdan veri alma (`input`)

## Bu Projede Kazandığım Beceriler

Bu proje sayesinde;

- Liste veri yapısını kullanarak verileri saklamayı,
- `for` döngüsü ile kayıtlı verileri listelemeyi,
- `while` döngüsü ile sürekli çalışan bir menü oluşturmayı,
- Koşul ifadeleri ile program akışını yönetmeyi,
- Kullanıcı etkileşimine dayalı basit konsol uygulamaları geliştirmeyi öğrendim.
