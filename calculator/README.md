# Hesap Makinesi

## Proje Hakkında

Bu proje, Python programlama dili kullanılarak geliştirilmiş basit bir hesap makinesi uygulamasıdır. Kullanıcı iki sayı girerek toplama, çıkarma, çarpma ve bölme işlemlerini gerçekleştirebilir. Seçilen işleme göre sonuç ekrana yazdırılmaktadır.

## Projenin Amacı

Bu proje, Python programlama dilinde kullanıcıdan veri alma, koşul ifadeleri kullanma ve temel matematiksel işlemleri uygulama konularını pekiştirmek amacıyla hazırlanmıştır.

## Özellikler

- Toplama işlemi
- Çıkarma işlemi
- Çarpma işlemi
- Bölme işlemi
- Hatalı işlem girişlerini kontrol etme

## Kullanılan Konular

- Python
- Değişkenler
- Koşul ifadeleri (`if`, `elif`, `else`)
- Kullanıcıdan veri alma (`input`)
- Temel matematiksel işlemler

## Bu Projede Kazandığım Beceriler

Bu proje sayesinde;

- Kullanıcıdan alınan verileri işlemeyi,
- Koşul ifadeleri ile program akışını yönetmeyi,
- Temel matematiksel işlemleri program aracılığıyla gerçekleştirmeyi,
- Farklı kullanıcı girişlerine göre uygun sonuç üretmeyi,
- Daha düzenli ve okunabilir Python kodu yazmayı öğrendim.
